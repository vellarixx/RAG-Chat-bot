# Корпоративный AI-консультант клиентской поддержки с RAG-базой знаний в Telegram

Готовое решение для автоматизации первой линии клиентской поддержки сервиса доставки правильного питания «FreshFit». Система объединяет локальную LLM-платформу Dify с векторной базой регламентов и асинхронный Telegram-интерфейс на Python (`aiogram 3`).

---

## Архитектура решения

```text
[ Пользователь в Telegram ]
             ↕ (long polling)
[ Python-агент: bot_dify.py (aiogram 3 + aiohttp) ]
             ↕ (REST API /v1/chat-messages)
[ Dify: http://localhost:8080 ]
      ├── Системный промпт (строгие правила + исключение галлюцинаций)
      ├── Векторный поиск (Vector Search по фрагментам регламента)
      └── LLM (Gemini / DeepSeek / Claude)

```

---

## Решаемые бизнес-задачи

* **Мгновенный ответ 24/7:** Сокращение времени ожидания клиентом ответа с 15+ минут до 2–3 секунд.
* **Исключение человеческих ошибок в расчетах:** Точный подсчет тарифов, длительности подписки и персонализированных скидок (например, 20% при заказе на месяц).
* **Защита от галлюцинаций (Zero-Hallucination):** Строгие инструкции системного промпта запрещают модели выдумывать условия, цены или меню, если их нет в прикрепленной базе знаний.
* **Лидогенерация:** Автоматический перевод диалога на сбор контактных данных (имя, телефон, выбранный рацион) при запросе заказа или пробного дня.

---

## Стек технологий

* **Оркестрация и RAG:** Dify (локальный Docker-стек на порту `8080`)
* **База знаний:** Сегментация текста по смысловым абзацам, векторное индексирование (Vector Search)
* **Языковые модели:** Gemini 1.5 Flash / Flash-Lite / GPT / DeepSeek
* **Интерфейс мессенджера:** Python 3.11+, `aiogram 3.15`, `aiohttp 3.10`
* **Режим соединения с Telegram:** Long Polling с расширенным таймаутом сессии (не требует белых IP-адресов и открытых наружу портов)

## Установка и запуск

### 1. Подготовка Dify

1. Разверните Dify в Docker (`http://localhost:8080`).
2. В разделе **Базы знаний (Knowledge)** создайте базу, загрузите текстовый регламент и выполните смысловое разбиение по абзацам.
3. В **Студии (Studio)** создайте приложение типа **Чат-бот (Chatbot)**, прикрепите созданную базу знаний в блок **Контекст (Context)**.
4. Перейдите в раздел **Доступ к API (API Access)** `</>` и сгенерируйте секретный ключ приложения (`app-...`).

### 2. Настройка Python-окружения

Создайте и активируйте виртуальное окружение, затем установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install aiogram aiohttp

```

### 3. Конфигурация переменных окружения

В файле `bot_dify.py` укажите полученные токены:

```python
TG_TOKEN = "ВАШ_ТОКЕН_ИЗ_BOTFATHER"
DIFY_API_KEY = "app-ВАШ_КЛЮЧ_ИЗ_DIFY"
DIFY_URL = "http://localhost:8080/v1/chat-messages"

```

### 4. Запуск бота

```powershell
python bot_dify.py

```

## Примеры работы бота

* **Запрос:** *«Сколько стоит рацион на 1200 ккал на 30 дней со скидкой?»*
**Ответ бота:** *«Стоимость тарифа "Снижение веса" (1200 ккал) составляет 1 500 рублей в день. При заказе на 30 дней действует скидка 20%. Итоговая стоимость за месяц составит 36 000 рублей (вместо 45 000 рублей). Желаете оформить заказ? Если да, пожалуйста, укажите ваше имя, номер телефона и выбранный рацион.»*
* **Запрос:** *«Доставляете ли вы пиццу пепперони?»*
**Ответ бота:** *«К сожалению, у меня нет такой информации в меню. Наш сервис специализируется на рационах здорового питания. Могу перевести вас на оператора для уточнения.»*
